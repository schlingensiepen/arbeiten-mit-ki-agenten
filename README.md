# Arbeiten mit KI-Agenten

Ein geschlossenes Script für Studierende des ersten Semesters: wie man mit
KI-Agenten strukturiert arbeitet, welche Werkzeuge dazu gehören und warum sie
so gebaut sind, wie sie gebaut sind.

Das Script entsteht gerade, die Kapitel folgen unter `script/`.

Behandelte Werkzeuge:

- [referenzprozess-softwareentwicklung](https://github.com/schlingensiepen/referenzprozess-softwareentwicklung)
- [clawbook-lehre](https://github.com/schlingensiepen/clawbook-lehre)
- [tmux-helper](https://github.com/schlingensiepen/tmux-helper)
- [peeragent](https://github.com/schlingensiepen/peeragent)
- [simple-a2a](https://github.com/schlingensiepen/simple-a2a)
