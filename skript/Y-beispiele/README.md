# Teil Y: Beispiele

Dieser Teil liegt außerhalb der Lesekette. Er enthält die Startprompts der beiden Beispiele, die das Skript tragen: die Lagerverwaltung, mit der die Teile A bis C arbeiten, und die Aufgabenverwaltung DONE, die ab dem Aufsetzen eines Projekts in Teil D benutzt wird. Die ersten beiden Prompts sind zum Nachmachen gedacht, der dritte zum Lesen. Die Kapitel der Lesekette verweisen an der passenden Stelle hierher.

1. [Lagerverwaltung](Y010-lagerverwaltung.md)
2. [DONE mit Referenzprozess](Y020-done-mit-referenzprozess.md)
3. [DONE ohne Regelwerk](Y030-done-ohne-regelwerk.md)
