# Teil B: Der naive Ansatz

Teil A hat zu einem laufenden Agenten geführt. Teil B baut damit etwas: eine Lagerverwaltung, auf dem direkten Weg von den Anforderungen zum fertigen Programm, mit einem Dokument je Schritt. Dieser Weg ist bewusst der einfache, und er trägt bis zur ersten Änderung. Wo er bricht, zeigt das letzte Kapitel an einem Fall; warum, begründet Teil C.
