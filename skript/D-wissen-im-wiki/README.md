# Teil D: Wissen im Wiki

Teil C hat begründet, warum das Wissen aus dem Gespräch heraus und auf die Platte muss. Dieser Teil zeigt die Form, die es dort bekommt: ein Wiki aus verlinkten Textdateien als Quelle der Wahrheit, ein Regelwerk, das dem Agenten sagt, wie er arbeitet, der feste Ablauf einer Sitzung, das Aufsetzen eines Projekts aus dem Referenzprozess und die Register, in denen Festlegungen eine Nummer und eine Begründung bekommen.
